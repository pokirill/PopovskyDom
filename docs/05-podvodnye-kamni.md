# 05. Подводные камни

Отсортировано по тому, насколько сильно бьёт по бюджету и срокам. 🔴 — может сломать план, 🟡 — заметные деньги, 🟢 — учесть.

## Конструкции и грунт

| | Риск | Почему опасно | Что делать |
|---|---|---|---|
| 🔴 | **Понижение пола цоколя на 0,7 м** | Сейчас пол на 0,3 м ниже земли, станет ≈ 1,0 м. Почти наверняка копаем ниже подошвы блоков ФБС → подводка фундамента участками, риск осадки и трещин в кирпиче выше | Обследование + геология до проекта. Сравнить с вариантом «2,7 только в пристройке» |
| 🔴 | **Вода на участке** (появилась после снятия верхнего слоя) | Углубление цоколя и пристройки делает воду главной проблемой: сырость, всплытие, плесень | Геология весной (максимальный уровень), кольцевой дренаж фундамента, гидроизоляция, дренаж участка, ливнёвка — **до** отделки |
| 🔴 | Выход из пристройки в сад «в уровень» | Пол пристройки на ≈ 1 м ниже земли. Терраса в «яме» собирает воду | Вертикальная планировка, подпорные стенки, приямок с водоотводом или пол пристройки выше пола цоколя |
| 🟡 | Несущая способность старых стен и плит | Мансарда над всем домом + пристройка + снег. Кирпич 2002 года, ФБС — состояние неизвестно, трещины уже есть | Обследование с расчётом. Возможны обвязочный пояс и усиление |
| 🟡 | Проёмы в ФБС | Стены из блоков без перевязки плохо переносят проёмы | Перемычки по расчёту КР, не «на глаз» |
| 🟡 | Стык старого и нового фундамента | Разная осадка → трещина по стыку | Деформационный шов, одинаковая глубина заложения или расчёт |
| 🟢 | Демонтаж мансарды и кровли = дом без крыши | Дождь заливает кирпич и плиты | Демонтаж только когда готовы материалы на кровлю; укрывной тент |

## Право и документы

| | Риск | Почему опасно | Что делать |
|---|---|---|---|
| 🔴 | **Отступы от границ** | Дом справа уже стоит ≈ 3 м от границы. Тамбур (1 м), гостевой дом (1 м) нарушают типовой норматив для жилых домов (3 м; для хозпостроек — 1 м) | Получить ГПЗУ. Тамбур — заранее понимать, что он будет **незарегистрированной реконструкцией** (проблемы при продаже, наследовании, споре с соседом). Гостевой дом — письменное согласие соседа или отступ 3 м |
| 🟡 | Собственник — не тот, кто строит и платит | Уведомления подаёт и договоры подписывает собственник. Вложения других членов семьи юридически не защищены | Нотариальная доверенность на ведение стройки. Семейная договорённость о долях — письменно |
| 🟡 | Уведомление о реконструкции | Без него — самовольная реконструкция, отказ в регистрации | Подать до начала работ; параметры в уведомлении = параметры проекта |
| 🟡 | Цоколь, ставший «1 этажом» | Этажность (≤ 3 надземных) и высота считаются по нормам; если цоколь будет заглублён больше чем наполовину, он считается подземным — это может помочь или помешать | Архитектор считает этажность заранее |
| 🟢 | Категория земли и ВРИ | Если в ЕГРН «для садоводства» на землях с/х — жилой дом допустим, но проверить, что ВРИ это позволяет | Выписка ЕГРН |
| 🟢 | Регистрация в конце | Техплан и ЕГРН нужны для продажи, наследования, страховки, прописки | Этап 12 в плане |

## Инженерия

| | Риск | Почему опасно | Что делать |
|---|---|---|---|
| 🔴 | **15 кВт может не хватить** | Электрокаменка 6–9 кВт + бойлер + кухня + гостевой дом + насос + возможная зарядка авто | Расчёт нагрузок в проекте; приоритетное отключение; газ для ГВС; при необходимости — доп. мощность заранее (это долго) |
| 🟡 | Котёл в цоколе | Для газового оборудования есть ограничения по размещению, окну, объёму, вентиляции | Проверить по СП 402.1325800 и ТУ газовиков до планировки |
| 🟡 | Вода «воняет» | Сероводород, железо, марганец — фильтр подбирается только по анализу. Плохая вода убивает котёл, бойлер, сантехнику | Анализ в аккредитованной лаборатории, затем проект водоподготовки |
| 🟡 | Септик при высоких грунтовых водах | Всплытие ёмкости, переполнение, выход стоков | Тип ЛОС под УГВ, анкеровка, принудительный сброс |
| 🟡 | Парная внутри дома | Влажность и пожарная опасность над/рядом с жилыми комнатами | Пароизоляция, вентиляция, электрокаменка с защитой, без дровяной печи |
| 🟡 | Второй свет | Теплопотери, шум на весь дом, перегрев летом, сложно мыть окна и чистить потолок | Расчёт ОВ, хорошие окна, шторы и жалюзи, акустика |
| 🟢 | Камин | Дымоход через три уровня, разделки, фундамент под камин, дорого | Закладываем место и дымоход сразу, сам камин можно позже |

## Стройка разными подрядчиками

| | Риск | Что делать |
|---|---|---|
| 🔴 | «Стыки ответственности»: следующий подрядчик говорит, что брак — у предыдущего | Приёмка каждого этапа с фото и актами; скрытые работы фотографировать до закрытия; технадзор на ключевых этапах |
| 🟡 | Сметы без ведомости объёмов несравнимы | Ведомости из проекта по каждому этапу |
| 🟡 | Зима между этапами | Консервация: кровля закрыта, контур закрыт, вода слита, временное отопление |
| 🟡 | Гарантии у разных бригад | Договор с гарантией, оплата по факту, удержание 5–10% до конца гарантийного срока |
| 🟢 | Доступ техники по дорогам СНТ | Узнать правила СНТ: вес, время, взносы за дороги |
| 🟢 | Воровство с открытой стройки | Ограждение, камера, материалы под заказ к сроку |
