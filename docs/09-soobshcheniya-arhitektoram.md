## 1. Первое сообщение

```
Здравствуйте! Ищу архитектора на реконструкцию дома в Красногорском г.о. (Петрово-Дальнее, СНТ). Дом 2002 года, 103 м², цоколь из блоков ФБС, этаж кирпичный. Хотим около 170 м²: пристройка 4 м со вторым светом, новая мансарда на 3 спальни, пол в цоколе опустить на 0,7 м. Первым делом нужно понять, что дешевле: перестраивать или снести и построить заново. Есть ТЗ, техпаспорт и схемы. Беретесь за такое? Если да, пришлю материалы и попрошу КП.
```

## 2. Второе сообщение (с файлами)

```
Тема: Реконструкция дома ≈170 м², Красногорск — запрос КП

Спасибо, что откликнулись. Прикладываю ТЗ, техпаспорт 2016 и схемы планировок. Схемы мои, концептуальные, их можно менять.

Коротко:
- работа в два этапа. Первый: обмеры, обследование конструкций, геология, топосъёмка и сравнение реконструкции с новым домом того же состава по цене и срокам. Второй: проект по выбранному варианту;
- стройка с мая 2027, по этапам разными подрядчиками. На каждый этап нужен свой комплект чертежей и ведомость объёмов;
- бюджет стройки дома до заезда около 13 млн, предел 17. Важно, чтобы вы считали цену решений и подсказывали, где сэкономить;
- на участке после снятия грунта стоит вода, геологии пока нет.

Чтобы сравнить предложения, ответьте, пожалуйста, по пунктам:
1. Что в ТЗ вы бы поменяли и что видите главным риском?
2. Как будете сравнивать реконструкцию и новый дом? Сколько стоит и сколько займёт первый этап?
3. 2–3 похожих объекта: реконструкция, надстройка, работа с фундаментом.
4. Кто делает конструктив и инженерию: ваша команда или партнёры?
5. Обмеры, обследование, геологию и топосъёмку делаете сами или ищем отдельно? Примерно сколько стоят.
6. Стоимость второго этапа по разделам и что в неё не входит.
7. Можете выдать чертежи и ведомости по этапам стройки? Есть пример?
8. Сроки: успеем сравнение к концу января и чертежи первых этапов к апрелю?
9. Авторский надзор, порядок оплаты, договор.

Могу созвониться на 20–30 минут, когда вам удобно. Ответ по пунктам жду до [дата].

[Имя], [телефон]
```

## Если не ответили за 3 рабочих дня

```
Добрый день! Напоминаю про реконструкцию дома в Красногорске. Интересен ли объект? Если да, жду КП до [дата]. Если нет, тоже напишите, пожалуйста.
```

## Проверочные вопросы на созвоне

| Вопрос | Хороший ответ |
|---|---|
| Снос и новый дом — дешевле? | Не отвечает сразу; сравнит после обследования, называет статьи: что даёт сохранение ФБС и кирпича, сколько стоит усиление |
| Как опускать пол цоколя на 0,7 м при воде на участке? | Сначала геология и обследование ФБС; подводка или усиление захватками; гидроизоляция и пристенный дренаж |
| Цоколь станет этажом? | Знает правило «заглублён больше чем наполовину — подземный», считает по ГПЗУ |
| Газовый котёл в цоколе можно? | Ссылается на СП 402.1325800 и требования газовой службы, называет условия |
| Тамбур и гостевой дом в 1 м от границы? | Объясняет риски (3 м для жилого, пожарные расстояния), предлагает варианты |
| Хватит ли 15 кВт на парную, бойлер, кухню? | Предлагает баланс нагрузок, а не сразу «докупите мощность» |

## Как сравнить

Шкала 1–5, итог = баллы × вес.

| Критерий | Вес | Что смотреть |
|---|---|---|
| Проактивность | 30% | ответ ≤ 2 дней; прочитал ТЗ; свои вопросы; нашёл риски; предложил выезд |
| Профессионализм | 40% | похожие объекты; свой конструктор и инженеры; понятный план сравнения; пример этапного комплекта; знание норм |
| Стоимость | 30% | полная цена: этап I + проект + изыскания + обследование + надзор; прозрачная разбивка; сроки |

| Кандидат | Проактивность | Профессионализм | Стоимость (полная) | Итог | Заметки |
|---|---|---|---|---|---|
| | | | | | |
| | | | | | |
| | | | | | |

**Красные флаги:** цена без чтения ТЗ; «обследование и конструктив не нужны»; нет ведомостей объёмов; «конечно, реконструкция» без обследования; «всё за 2–3 недели»; нет договора.
