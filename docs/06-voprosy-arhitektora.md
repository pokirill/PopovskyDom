# 06. Вопросы архитектора и наши ответы

Подготовка к первой встрече. ✅ — ответ есть, ❓ — решить до встречи или вместе с архитектором.

## Общее

| Вопрос | Ответ |
|---|---|
| Кто будет жить? | ✅ Постоянно — родители. Эпизодически — сын, дочь с мужем, гости |
| Бюджет на стройку? | ✅ ≈ 6–7 млн в 2027, ≈ 6 млн в 2028. Ориентир на дом до заезда — ≤ 13 млн, потолок ≤ 17 млн. Нужны варианты удешевления |
| Сроки? | ✅ Стройка с мая 2027, заезд — к Новому 2029 году |
| Кто принимает решения? | ✅ Финальное слово — у сына (владельца проекта), согласование с родителями |
| Стиль? | ✅ Неоклассика, «небольшая усадьба». Референсы — ❓ пришлём |
| Почему не снести и не построить новый? | ❓ Хотим сохранить, если выгодно. **Просим посчитать оба варианта.** По нашей грубой оценке они близки по деньгам |
| Нужен ли авторский надзор? | ❓ На ключевых этапах — скорее да, обсудить цену |
| Нужен дизайн интерьеров? | ✅ Нет, позже |

## Дом

| Вопрос | Ответ |
|---|---|
| Сколько спален? | ✅ 3 на уровне 3 + кабинет-гостевая на уровне 2. Площадь дома ≈ 170 м² |
| Спальня на первом этаже для пожилых? | ✅ Не нужна: запасной вариант — гостевой дом |
| Кухня открытая или закрытая? | ✅ Открытая кухня-гостиная в пристройке |
| Сколько человек за столом? | ❓ Предлагаем 8–10 |
| Камин дровяной или газовый? | ✅ Дровяной, для красоты и резервного обогрева |
| Парная: электро или дрова? | ❓ Склоняемся к электро (безопаснее в доме), но 15 кВт… — обсудить |
| Санузлов на уровне 3? | ✅ Один (v0.2), второй — опция |
| Нужна ли гардеробная у каждой спальни? | ❓ Шкафы-гардеробы в спальнях + большая общая гардеробная-постирочная |
| Мастерская: под что? | ❓ Инструменты, верстак, пайка. Шум, пыль, вытяжка? Описать подробнее |
| Высота потолков? | ✅ Уровень 1 — не ниже 2,5–2,6 чистовая; второй свет ≈ 5–6 м |
| Окна: какие, какого цвета, шпросы? | ❓ Под неоклассику — решить с архитектором |
| Кровля: материал? | ❓ Металлочерепица / мягкая / композит — предложить по цене и стилю |
| Можно оставить лестницу в веранде? | ✅ Нет: на её месте душ+WC и парная, лестница переносится |
| Вход в дом где? | ✅ Через тамбур-прихожую у восточной стены пристройки, в уровень земли. Выход в сад — на север из пристройки |
| Нужен ли подвал? | ✅ Нет, уровень 1 и так частично в земле |

## Участок и сети

| Вопрос | Ответ |
|---|---|
| Рельеф, уклон? | ❓ Нужна топосъёмка. Цоколь сейчас заглублён на 0,3 м |
| Грунтовые воды? | ✅ Раньше проблем не было; в 2026 после снятия верхнего слоя стоит вода. ❓ Нужна геология |
| Газ? | ✅ Магистраль перед участком. ❓ Статус ТУ / договора |
| Электричество? | ✅ 15 кВт |
| Вода? | ✅ Поселковая скважина 100+ м, на участок заведена, пахнет. ❓ Анализ |
| Канализация? | ✅ Нет, нужен септик/ЛОС (оценка 200–250 тыс.) |
| Где парковка, сколько машин? | ❓ Навес-парковка спереди справа + плитка; 2–3 машины? Нужна ли зарядка для электромобиля или гибрида? |
| Пруд: размер и тип? | ✅ До 100 м². ❓ Естественный или плёнка, связь с дренажом |
| Забор и ворота? | ❓ Менять ли фасадный забор, откатные или распашные ворота |
| Отступы от соседей? | ✅ Хотим 1 м для домика и тамбура. ❓ Архитектор оценит риски, соседи ≈ 3 м? |
| Соседние дома: где стоят? | ❓ Покажет топосъёмка |
| Полив, наружное освещение? | ❓ Скорее да: автополив газона, подсветка дорожек |

## Гостевой дом

| Вопрос | Ответ |
|---|---|
| Назначение? | ✅ Гостевая квартира + запасной дом для родителей. Круглогодичный |
| Состав? | ✅ Спальня, кухня-гостиная, санузел + крытая мангальная зона под той же крышей |
| Когда строим? | ✅ Последним этапом, но трассы прокладываем сразу |
| Отопление? | ❓ Газ (ещё одна точка) или электро (15 кВт…) |
